# Brackwater

Brackwater is a fictional company used to test this agent. It makes one product: Tidewatch, a sensor that tells harbour masters when a mooring line is about to fail.

Brackwater is one engineer and a set of software agents. There is no sales team and no office: the work happens on site, in the harbour.

Tidewatch is in pilot in two harbours. The harbours are not named on this site.
